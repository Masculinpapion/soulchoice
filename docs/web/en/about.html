About SoulChoice

SoulChoice is a social network for shared plans. Post an invitation to a real event — dinner, a concert, an exhibition, a walk — or apply to someone else's. The invitation owner picks who comes along, and a chat opens only after that choice. Everyone sees one shared feed: there are no gender or age filters.

Every profile passes mandatory selfie verification — no fakes and no borrowed photos.
